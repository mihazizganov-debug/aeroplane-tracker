# ✈️ Aeroplane Tracker

**Курсовая работа по интеграции с внешними API**  
Программа для получения информации о самолетах в воздушном пространстве любой страны с использованием OpenSky Network и OpenStreetMap.

---

## 🛫 О проекте

**Aeroplane Tracker** — это консольное приложение, которое:

1. По запросу пользователя определяет географические границы указанной страны через **Nominatim (OpenStreetMap)**.
2. Запрашивает данные о самолетах, находящихся в воздухе или на земле в этом регионе, через **OpenSky Network API**.
3. Преобразует сырой ответ в список объектов класса `Aeroplane` с валидацией и методами сравнения.
4. Позволяет фильтровать, сортировать и сохранять полученную информацию в JSON-файл.

Проект разработан в рамках курсовой работы и демонстрирует навыки работы с API, ООП (наследование, инкапсуляция, абстрактные классы, миксины), обработки исключений, модульного тестирования и типизации.

---

## 🔥 Основные возможности

- **Поиск самолетов по названию страны** — введите страну (например, Russia, USA, Germany) и получите список всех воздушных судов над ней.
- **Топ N по высоте** — отсортируйте самолеты по высоте полета и выведите заданное количество.
- **Фильтр по стране регистрации** — оставьте только самолеты, зарегистрированные в интересующей вас стране.
- **Сравнение двух самолетов** — выберите два самолета из списка и узнайте, какой летит выше и быстрее.
- **Сохранение данных в JSON** — сохраните текущую выборку в файл, избегая дубликатов по ICAO24.
- **Загрузка из JSON** — загрузите ранее сохраненные данные и работайте с ними офлайн.
- **Просмотр статистики сохраненных самолетов** — группировка по странам регистрации.

## 🛠 Технологии

- **Python 3.13+**
- **Requests** — для HTTP-запросов к API
- **python-dotenv** — для безопасного хранения учетных данных OpenSky (опционально)
- **Pytest + pytest-cov** — модульное тестирование и измерение покрытия (94%)
- **Poetry** — управление зависимостями и упаковка
- **Flake8, Black, isort, mypy** — поддержка качества кода и статическая типизация

## ⚙️ Установка и запуск

### Требования
- Python 3.13 или выше
- Poetry (рекомендуется) или pip

### Шаги

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/mhazizganov-debug/aeroplane-tracker.git
   cd aeroplane-tracker

2. Создайте виртуальное окружение и установите зависимости (через Poetry)

poetry install
poetry shell

3. (Опционально) Настройте учетные данные OpenSky

Зарегистрируйтесь на opensky-network.org

Скопируйте файл .env.example в .env и укажите свои логин/пароль:

   OPENSKY_USERNAME=your_username
   OPENSKY_PASSWORD=your_password

4. Запустите программу

    python main.py
