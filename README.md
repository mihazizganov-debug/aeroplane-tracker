# ✈️ Aeroplane Tracker

**Курсовая работа по интеграции с внешними API**  
Программа для получения информации о самолетах в воздушном пространстве любой страны с использованием OpenSky Network и OpenStreetMap.

---

## 🛫 О проекте

**Aeroplane Tracker** — это консольное приложение, которое:

1. По запросу пользователя определяет географические границы указанной страны через **Nominatim (OpenStreetMap)**.
2. Запрашивает данные о самолетах, находящихся в воздухе или на земле в этом регионе, через **OpenSky Network API**.
3. Преобразует сырой ответ в список объектов класса `Aeroplane` с валидацией и методами сравнения.
4. Позволяет фильтровать, сортировать и сохранять полученную информацию в JSON-файл.

---

## 🔥 Основные возможности

- **Поиск самолетов по названию страны** — введите страну и получите список всех воздушных судов над ней
- **Топ N по высоте** — отсортируйте самолеты по высоте полета
- **Фильтр по стране регистрации** — только самолеты нужной страны
- **Сравнение двух самолетов** — узнайте, какой летит выше и быстрее
- **Сохранение данных в JSON** — без дубликатов по ICAO24
- **Загрузка из JSON** — работайте с данными офлайн
- **Просмотр статистики** — группировка по странам регистрации

---

## 🛠 Технологии

- **Python 3.13+**
- **Requests** — HTTP-запросы к API
- **python-dotenv** — хранение учетных данных
- **Pytest + pytest-cov** — тестирование (94% покрытия)
- **Poetry** — управление зависимостями
- **Flake8, Black, isort, mypy** — качество кода
